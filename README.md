# szkupienpeti.github.io

Szkupien Péter személyes weboldala.

Statikus oldal, nincs build lépés és JavaScript sem: a teljes tartalom az `index.html`-ben, a megjelenés a `styles.css`-ben van. A betűkészlet (Newsreader, OFL licenc) a `fonts/` mappában található.

## Helyi futtatás

```bash
npx http-server -p 4173
```
